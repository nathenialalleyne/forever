# Changelog

All notable changes to Forever are documented in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased] / 0.0.0-dev

This is the initial foundation milestone. It establishes the project and its safety
contracts, not a playable feature release.

### Added

- Fabric 26.2 project foundation with the pinned Java, Loader, API, Loom, Gradle, and
  JUnit baseline.
- Separate common and client source-set guidance and a dedicated-server GameTest smoke
  path.
- AI-readable vision, design, architecture, dependency, workflow, save-safety, roadmap,
  and backlog documentation.
- Matcha acquisition, pinning, disposable development installation, and standalone
  audit-tool workflow documentation.
- CI instructions for Java 25, the root mod build, root unit tests, and the separate
  audit-tool test build without fetching Matcha.

### Not implemented

- No gameplay systems are implemented in this milestone. Mastery, equipment condition
  and repair, settlements, careers, Mason progression, Field Guide content, storage,
  logistics, transportation, seasons, food traits, shops, workers, and related systems
  remain future backlog work.
